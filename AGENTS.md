# Agent instructions

Read **[SKILLS.md](SKILLS.md)** before changing this repository.

`SKILLS.md` is the living skills, requirements, and architecture file.

- Follow its Source of truth, hard requirements, and playbooks.
- After any behavior change, **update `SKILLS.md` in the same commit** and push it to GitHub.
- Keep `README.md`, `docs/EXCEL_ANALYSIS.md`, and `docs/architecture.svg` consistent with `SKILLS.md` (the SVG is the system picture — update it when `deploy/` or the topology changes).
- Operator recovery commands live in `docs/RECOVERY.md`.
